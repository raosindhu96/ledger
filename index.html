✦ Smart categorise — API key

Smart categorise uses Claude AI with web search to identify merchants and assign categories. It requires your own Anthropic API key. The key is only held in memory and sent directly to Anthropic — it's never stored or logged anywhere.

Get a key at platform.anthropic.com → API Keys. Usage costs are minimal — typically a few cents for a full month of transactions.
